# 抽样和熵校准口径

PSU身份是stratum与psu二元组，每行机器人id唯一且特征齐全。base_weight=d，lower/upper是正下界和有限上界比例，lower<=upper；副本的比例界施加在经过删PSU放大后的d上，删除行不参与副本变量。目标边际各自和必须等于total。指示编码任选每特征的一个参考类并保留总量，线性相关约束可以删除但须核对原全约束一致性。正目标且没有样本支撑的类别应单独诊断。稀疏交叉格不自动补造记录。

点估计为sum w*y/sum w。ESS=(sum w)^2/sum w²，只描述权重集中度，不冒充考虑整群相关后的设计有效样本数。jackknife在每层每PSU各出一个副本，不能对行独立抽样；方差参照该层副本均值，不使用其他层均值。区间为点估计±z×SE，可展示截在[0,1]的可视范围但原统计区间必须保留。replicate-support-loss删除H1P1后rare=yes无支撑。

已有domain只给基础权重比例和PSU列表，不做边际校准、对偶或副本方差。
