# 抽样和熵校准口径

PSU身份是stratum与psu二元组，每行机器人id唯一且特征齐全。base_weight=d，lower/upper是正下界和有限上界比例，lower<=upper；副本的比例界施加在经过删PSU放大后的d上，删除行不参与副本变量。目标边际各自和必须等于total。指示编码任选每特征的一个参考类并保留总量，线性相关约束可以删除但须核对原全约束一致性。正目标且没有样本支撑的类别应单独诊断。稀疏交叉格不自动补造记录。

## 有界熵校准

点估计为带比例界的熵校准（raking）。设计矩阵 X 含一个总量列和每个分类特征去掉参考类后的指示列，求解

    最小化  f(w)=Σ w_i·log(w_i/d_i) − w_i + d_i
    约束    Xᵀw = target，  lower_i·d_i ≤ w_i ≤ upper_i·d_i

比例界在原问题中同时生效，不做“先无界 raking 再截尾”。对偶变量 λ 下逐行闭式解为 w_i=clip(d_i·exp((Xλ)_i), L_i, U_i)，在对偶空间用牛顿法最大化凹分片二次可微函数，Hessian 为 −Xᵀdiag(v)X（界内行 v=w，触界行 v=0），奇异时岭项兜底并退回最速上升，带 Armijo 回溯与信赖域步长截断。

求解状态互斥且不通过放宽边际“凑通过”：

- `optimal` / `optimal_redundant_constraints`：达到容差；后者表示存在线性相关但一致的约束，已去冗余并在审计字段保留表示关系。
- `target_inconsistent`：某边际类别数量之和不等于 total。
- `unsupported_target`：某指示列有正目标但样本中该列恒为零（无正质量支撑）。
- `infeasible_dependent_constraints`：相关约束对目标的要求互相矛盾（冗余列目标与其主元列线性表示不一致）。
- `bounded_infeasible`：无界条件可满足，但盒约束与仿射约束交集为空；用 Dykstra 交替投影给出盒内最小残差点作为证据。
- `not_converged`：迭代上限或残差停滞后仍未达容差，且投影确认可行域非空；只报未收敛，保留最佳努力残差，不返回点估计。

成功时报告每条约束的目标值、加权达成值与残差，目标函数与对偶目标及对偶间隙，逐行平稳性残差与截尾违例，界激活行（下界/上界），以及主元列的对偶乘数（去冗余列显式为 null，其线性表示在约束审计中给出）。

点估计为 sum w·y / sum w。ESS=(sum w)²/sum w²，只描述权重集中度，不冒充考虑整群相关后的设计有效样本数；同时给出最大权重占比 max w / sum w。边际校准只强制已知边际一致，若上传行为在未观测维度上存在自选择，校准不能保证消除自选择偏差，区间也不覆盖覆盖性偏差。

## 分层 delete-one-PSU jackknife

jackknife在每层每PSU各出一个副本，不能对行独立抽样。删去某层一个PSU后，同层剩余行基础权重乘 m_h/(m_h−1)，其他层不变；每个副本用放大后的基础权重重新计算比例界，并对原目标重新做完整有界校准（含去冗余与触界求解），不复用全样本权重。

方差按层累加：

    V = Σ_h (m_h−1)/m_h · Σ_a (θ̂_{ha} − θ̄_h)²，  θ̄_h = (1/m_h)Σ_a θ̂_{ha}

参照该层副本均值，不使用其他层均值。区间为点估计 ± z×SE，同时给出截在 [0,1] 的可视区间，但原统计区间必须保留。出现以下任一情形时保留点估计但不报有效区间，标准误与区间置 null 并记录原因：单 PSU 层（m_h=1 无法形成副本）、任何副本不可行或不收敛。replicate-support-loss 删除 H1P1 后 rare=yes 无支撑，副本命中 unsupported_target。

## 编码不变性

增加冗余分类指示列（全 dummy 编码）、改换参考类、重排行序或列序，只改变约束系统的表示而不改变可行域与熵最优解；模块对相关列做 Gram 系统表示核对后去冗余，最终权重与估计量在数值容差内保持不变。

已有domain只给基础权重比例和PSU列表，不做边际校准、对偶或副本方差。所有合成资料仅为算法核对，不代表真实机器人总体。
